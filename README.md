# oekonometrie_und_wirtschaftsstatistik_seminar
Projekt von Rusmir Pavlovic und Moritz Reischl zum EU Emissins Trading System. Wir untersuchen, wie sich EU ETS-Zertifikatpreise auf den wirtschaftlichen Erfolg von energieintensiven Industrien im Vergleich zu anderen Industrien in Europa auswirkt.

Die Ergebnisse aus dem Paper und Präsentationen können reproduziert werden, indem alle .R Dateien im Ordner "code" mit der Prefix-Nummer aufsteigend vollständig ausgeführt werden, d. h. 0_package_installer.R, 1_staging_mapping_ets_nace.R usw.
